# HyRange

HyRange takes pair counts and node degrees and finds the hyperedges that must occur in every compatible reconstruction.

## Quick start

Use Python 3.12. A CPU is enough. Download [HyRange-code.zip](HyRange-code.zip), extract it, and run these commands from the extracted `HyRange` folder.

```bash
python -m pip install -r requirements.txt
python -I -B -X utf8 examples/quick_start.py
```

See [the experiment guide](REPRODUCING.md) for commands and the `data/README.md` in the archive for benchmark setup. The code is available under the [MIT License](LICENSE).
