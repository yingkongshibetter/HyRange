# HyRange

HyRange takes pair counts and node degrees and finds the hyperedges that must occur in every compatible reconstruction.

## Quick start

Use Python 3.12. A CPU is enough. Clone the repository and run these commands.

```bash
git clone https://github.com/yingkongshibetter/HyRange.git
cd HyRange
python -m pip install -r requirements.txt
python -I -B -X utf8 examples/quick_start.py
```

See [the experiment guide](REPRODUCING.md) for commands and [the data instructions](data/README.md) for benchmark setup. The code is available under the [MIT License](LICENSE).
